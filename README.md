# Student Assignment Portal with DevOps Automation

A web portal where student assignment submissions automatically appear on a website. Data is course from Google Forms via Google Apps Script API.

## Project Architecture
- **Frontend**: HTML, CSS, JavaScript
- **Backend/API**: Google Apps Script
- **Data Source**: Google Forms & Sheets
- **CI/CD**: GitHub Actions
- **Hosting**: Netlify
- **Alerts**: Slack Webhook
